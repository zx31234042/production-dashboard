## 1. 项目概述

### 1.1 项目目标（可验收）

- 设备硬件运行状态与核心参数**秒级同步**，状态颜色标识直观可辨；
- **航行器深度与航行速度为主要实测展示对象**，配合工单、测试标准、进度全流程可视化（C-31）；
- 当班生产、质检、效率数据**自动统计**，替代人工纸质台账；
- 设备故障、参数超标、生产超时**实时高亮预警**，展示处理进度并闭环留痕；
- 设备全生命周期维保、运行、检修数据**留痕可查**；
- **看板主机直接与 MES 服务器通讯**：接收派工信息，并按附录 2 规范上传 13 个字段（C-29）。

### 1.2 系统边界（按 C-29、C-30 调整）

**范围内（本项目负责）：**

- 看板显示端软件（固定头部区 + 8 个标签页 + 设置页）；
- **看板主机 + 独立 75″ 显示终端**（另项采购，自成一套交付物）；
- 看板服务：接收上位机数据、落库、判定、统计、告警；
- **IF-D 与 PC 上位机的数据接口（接收侧）**；
- **IF-A / IF-B 与 MES 的双向接口（本项目实现）**：接收派工/物料/工艺信息，按附录 2 上传 13 个字段；
- 本地数据库、配置、日志、开机自启与无人值守保障；
- 维保/公告/异常闭环的本机录入与留痕；
- 历史查询与报表导出（FR-10）。

**范围外：**

- **19 台相机的取值/整合规则**（由 PC 上位机确定，本项目不定义、不二次聚合，见 C-30）；
- 相机、补光灯、深度传感器、同步控制器的接入与采集程序（PC 上位机侧，父项目范围）；
- 父项目的 75″ 图像总览大屏及其显示逻辑；
- MES 侧接口的开发；
- 车间网络、机柜、电视挂架、电源等弱电施工；
- 远程运维/远程操控（隔离局域网）。

### 1.3 用户角色与使用场景

| 角色 | 关注内容 | 交互方式 |
| --- | --- | --- |
| 现场操作员 | 当前工单、航行器深度与速度、进度、报警 | 只看不操作 |

## 3. 系统架构与数据流（按 C-29 恢复 MES 直连）

### 3.1 分层架构

**分层构成**

| 层 | 组成 |
| --- | --- |
| **展示层**：看板前端（看板主机 · 全屏 Kiosk · 独立 75″ 终端） | 固定头部区；信息展示区：设备状态 / 任务数据 / 班次信息 / 生产统计 / 设备异常 / 维保台账 / 公告备注 / 操作设置（共 8 个标签页） |
| **服务层**：看板服务（Windows 服务） | ① 接收上位机数据　② 业务校验　③ 落库　④ 异常判定　⑤ 班次统计　⑥ MES 双向通讯 |
| **数据层**：本地数据库 | SQLite / PG；任务曲线固化；保留 1 年 + 每日备份 |

**层间连接**

| 连接 | 通道 | 对端与内容 | 前置条件 |
| --- | --- | --- | --- |
| 展示层 ↔ 服务层 | **SSE 秒级推送**（IF-E；1 s 心跳与断线重连）；写操作用 HTTP POST | 看板前端 ↔ 看板服务 | — |
| 服务层 ↔ 设备 | 局域网 **HTTP / WebSocket**（IF-D） | **PC 上位机**（父项目 7.5 / 10.4）：采集相机、补光灯、深度传感器、同步控制器数据，**整合 19 台相机结果后提供单一结果值** | 接口规范待上位机方提供（Q-21） |
| 服务层 ↔ MES | 内网 **HTTP(S)**（IF-A / IF-B，C-29） | **MES 系统**：派工 / 物料 / 工艺下发；接收附录 2 的 13 字段上报 | 接口地址与契约待 MES 方确认（Q-23、Q-28） |
| 服务层 ↔ 数据 | 本地访问 | 本地数据库（SQLite / PG） | — |

**关键点：**
- 看板**不直连相机/PLC**，实时测量数据由 **PC 上位机**经局域网提供（IF-D）；
- **MES 通讯由 MES 服务器与本机直接进行，不经过相机系统上位机**（C-29）。

### 3.2 关键数据流

1. **测量流：** 相机/补光灯/深度传感器/同步控制器 → PC 上位机（整合 19 台相机数据）→ **IF-D** → 看板服务 → 本地库 + 实时缓存；
2. **派工流：** MES 服务器 → **IF-A** → 看板服务（当前工单与测试标准）；
3. **上报流：** 看板服务 → **IF-B** → MES 服务器（附录 2 的 13 个字段，含深度与速度）；
4. **展示流：** 看板服务 → 前端 1 s 推送；
5. **留痕流：** 本机解锁后的维保录入、公告编辑、异常闭环 → 本地库 + 操作日志。

## 15. 假设与前提

1. **PC 上位机**由父项目/第三方负责，采集并整合 19 台相机数据后经 IF-D 提供给看板；**取值/聚合规则由上位机确定，本项目不定义**（C-30）；
