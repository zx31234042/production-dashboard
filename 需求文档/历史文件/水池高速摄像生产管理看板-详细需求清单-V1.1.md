## 1. 项目概述

### 1.1 项目目标（可验收）

- 设备硬件运行状态与核心参数**秒级同步**，状态颜色标识直观可辨；
- 在测工单、测试标准、实测数据、进度**全流程可视化**；
- 当班生产、质检、效率数据**自动统计**，替代人工纸质台账；
- 设备故障、参数超标、生产超时**实时高亮预警**，展示处理进度并闭环留痕；
- 设备全生命周期维保、运行、检修数据**留痕可查**；
- 按《MES与产线系统接口定义》与 MES 双向对接：接收派工/物料/工艺信息，上报报工、异常、关键运行参数、OEE 等。

### 1.2 系统边界

**范围内：**

- 看板显示端软件（固定头部区 + 8 个标签页 + 设置页）；
- 看板服务（接收上位机数据、落库、判定、统计、告警）；
- 与产线上位机的局域网数据接口（接收侧）；
- 与 MES 的双向接口（接口定义 §1.1 提供侧 + §1.2 调用侧）；
- 本地数据库、配置、日志、开机自启与无人值守保障；
- 维保/公告/异常闭环的本机录入与留痕；
- 历史查询与报表导出（新增范围，见 FR-10）。

**范围外：**

- 产线上位机上运行的采集程序及其与 PLC/相机/传感器的对接（由上位机方负责，本系统只定义双方接口）；
- MES 侧接口的开发；
- 车间网络、机柜、电视挂架、电源等弱电施工；
- 远程运维/远程操控（变更 C-04，网络为隔离局域网）。

### 1.3 用户角色与使用场景

| 角色 | 关注内容 | 交互方式 |

| 现场操作员 | 当前工单、实测数据、进度、报警 | 只看不操作 |

| 设备维保人员 | 维保周期、检修记录、故障台账 | 本机解锁后录入 |

## 3. 系统架构与数据流

### 3.1 分层架构（按变更 C-02 调整）

```
┌──────────────── 展示层：看板前端（本看板主机 · 全屏 Kiosk） ────────────────┐
│  固定头部区 │ 信息展示区（设备状态 / 任务数据 / 班次信息 / 生产统计 /        │
│             │             设备异常 / 维保台账 / 公告备注 / 操作设置）        │
└──────────────────────────────────┬──────────────────────────────────────────┘
                                   │ 本地 WebSocket / HTTP（秒级推送）
┌──────────────────────────────────┴──────────────────────────────────────────┐
│ 服务层：看板服务（Windows 服务）                                             │
│ ①接收上位机数据 ②业务校验 ③落库 ④异常判定 ⑤班次统计核算 ⑥MES 双向对接      │
└──────┬──────────────────────────────┬───────────────────────────────────────┘
       │ 局域网 HTTP/WebSocket        │ 内网 HTTP(S)（MES 提供接口，调用侧）
┌──────┴───────────────────────┐  ┌───┴─────────────────────────┐  ┌──────────────┐
│ 产线上位机（另一台 Windows）  │  │ MES 系统                     │  │ 本地数据库    │
│  └─ PLC / 相机 / 深度传感器   │  │ 派工/物料/工艺下发（调用本系统）│  │ SQLite/PG     │
└──────────────────────────────┘  └─────────────────────────────┘  └──────────────┘
```

**关键点：** 本看板主机**不直接连接 PLC / 相机 / 深度传感器**，所有实时工艺数据由产线上位机采集后经局域网传输（变更 C-02）。

### 3.2 关键数据流

1. **采集流：** PLC/相机/传感器 → 上位机（采集程序）→ 局域网接口 → 看板服务 → 本地库 + 实时缓存；
2. **派工流：** MES 调用本系统提供的接口 → 下发派工/物料/工艺信息 → 看板服务落库并更新当前工单与测试标准；
3. **上报流：** 看板服务（或上位机，见 Q-22）调用 MES 提供的接口 → 上报报工、生产异常、关键运行参数、OEE、人员班组等；
4. **展示流：** 看板服务 → 前端 1 s 推送；
5. **留痕流：** 本机解锁后的维保录入、公告编辑、异常闭环 → 本地库 + 操作日志。

## 15. 假设与前提

1. 产线上位机侧采集程序由甲方/第三方负责，本系统仅定义并实现双方接口的接收侧（Q-21 未关闭前，IF-D 存在返工风险）；
2. MES 上报执行方以 Q-22 结论为准；若由上位机执行，则 IF-B 工作量从本项目范围中移除，仅保留展示需求；
3. 《MES与产线系统接口定义》为接口字段的权威描述，但与原文附录 2 的冲突项以 Q-23 冻结结论为准；
4. 网络为隔离局域网，不可访问互联网，因此不提供远程运维，前端资源全部本地化；
5. 设备编号唯一且稳定；
6. 班次为固定规则配置（如需动态排班需追加需求）；
7. 测试标准阈值（设定深度/增益/帧率/快门）需由 MES 工艺信息或本机配置提供，接口定义中暂无对应字段；
8. **显示输出为 4K@30Hz，内存固定 8 GB 且不可升级**，界面设计与运行时选型须在该性能与刷新率约束内完成；
9. 设备与任务的主标识统一为 equipCode / procOrderNo，原文附录 2 最新版字段表已与之一致（其报文示例尚未同步）。
