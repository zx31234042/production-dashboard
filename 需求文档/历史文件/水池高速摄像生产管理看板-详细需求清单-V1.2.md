## 1. 项目概述

### 1.1 项目目标（可验收）

- 设备硬件运行状态与核心参数**秒级同步**，状态颜色标识直观可辨；
- 在测工单、测试标准、实测数据、进度**全流程可视化**；
- 当班生产、质检、效率数据**自动统计**，替代人工纸质台账；
- 设备故障、参数超标、生产超时**实时高亮预警**，展示处理进度并闭环留痕；
- 设备全生命周期维保、运行、检修数据**留痕可查**；
- 按附录 2 规范的数据由 **PC 上位机**上报 MES（变更 C-20）。

### 1.2 系统边界（按变更 C-17、C-20 调整）

**范围内（本项目/本看板负责）：**

- 看板显示端软件（固定头部区 + 8 个标签页 + 设置页）；
- **看板主机 + 独立 75″ 显示终端**（另项采购，自成一套交付物）；
- 看板服务：接收 PC 上位机数据、落库、判定、统计、告警；
- **IF-D 与 PC 上位机的局域网数据接口（接收侧）**；
- 本地数据库、配置、日志、开机自启与无人值守保障；
- 维保/公告/异常闭环的本机录入与留痕；
- 历史查询与报表导出（FR-10）。

**范围外：**

- **MES 双向接口 IF-A / IF-B —— 由 PC 上位机实现**（本项目不实现，见 C-20）；
- 相机、补光灯、深度传感器、同步控制器的接入与 PLC/采集程序（PC 上位机侧，父项目范围）；
- 父项目的 75″ 图像总览大屏及其显示逻辑；
- 车间网络、机柜、电视挂架、电源等弱电施工；
- 远程运维/远程操控（隔离局域网）。

## 3. 系统架构与数据流（按变更 C-20 调整）

### 3.1 分层架构

```
┌──────────── 展示层：看板前端（看板主机 · 全屏 Kiosk · 独立 75″ 终端） ────────────┐
│  固定头部区 │ 信息展示区（设备状态 / 任务数据 / 班次信息 / 生产统计 /             │
│             │             设备异常 / 维保台账 / 公告备注 / 操作设置）           │
└──────────────────────────────────┬─────────────────────────────────────────────┘
                                   │ 本地 WebSocket / HTTP（秒级推送）
┌──────────────────────────────────┴─────────────────────────────────────────────┐
│ 服务层：看板服务（Windows 服务）                                                │
│ ①接收 PC 上位机数据 ②业务校验 ③落库 ④异常判定 ⑤班次统计核算                   │
└──────┬───────────────────────────────────────────────┬─────────────────────────┘
       │ 局域网 HTTP/WebSocket（IF-D，本项目实现）      │ 本地库
┌──────┴────────────────────────────────┐        ┌─────┴──────────────┐
│ PC 上位机（父项目 7.5/10.4）           │        │ 本地数据库          │
│ └ 相机 / 补光灯 / 深度传感器 / 同步控制器│        │ SQLite/PostgreSQL   │
│ 承担 MES 双向接口（IF-A / IF-B）        │        └────────────────────┘
└──────┬────────────────────────────────┘
       │ 内网 HTTP(S)（MES 提供/接收接口）
┌──────┴─────────────────────────┐
│ MES 系统（派工下发、数据接收）    │
└────────────────────────────────┘
```

**关键点：** 看板**不直连 MES、不直连相机**。所有实时数据与工单信息均由 **PC 上位机**经局域网提供（C-20）；MES 上报同样由 PC 上位机执行。

### 3.2 关键数据流

1. **采集流：** 相机/补光灯/深度传感器/同步控制器 → PC 上位机（父项目）→ **IF-D** → 看板服务 → 本地库 + 实时缓存；
2. **派工流：** MES → PC 上位机（IF-A）→ **IF-D** → 看板服务（当前工单与测试标准）；
3. **上报流：** PC 上位机 → MES（IF-B，含帧率/增益/快门/深度/速度/状态等 12 个字段）——**本项目范围外**；
4. **展示流：** 看板服务 → 前端 1 s 推送；
5. **留痕流：** 本机解锁后的维保录入、公告编辑、异常闭环 → 本地库 + 操作日志。

## 15. 假设与前提

1. **PC 上位机**由父项目/第三方负责，本系统仅实现 IF-D 接收侧；Q-21 未关闭前 IF-D 存在返工风险；
2. **MES 双向接口（IF-A/IF-B）由 PC 上位机实现**，不计入本项目工作量（C-20）；
3. 看板主机、独立 75″ 显示终端与看板软件由本项目**另项采购**，不进入父项目 16.1 供货清单（C-17）；
4. 显示输出为 4K@30Hz，内存固定 8 GB 且不可升级；
5. 设备编号为整套系统 1 个编号（覆盖 19 台相机）；
6. 本看板服务**产品检验工况**，产量与质量指标适用；
7. 网络为隔离局域网，不可访问互联网，因此不提供远程运维，前端资源全部本地化；
8. 班次为固定规则配置（如需动态排班需追加需求）；
9. 深度取控制系统设定值；帧率为相机实际工作帧率；
10. 交付与验收时间与父项目 **M6 现场终验收（12 月底）** 对齐，验收方式为实物演示验收。
