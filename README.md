# 水池高速摄像生产管理看板

面向水池高速摄像产品检验设备的生产管理看板（75 寸电视大屏显示）。
本仓库包含**前端演示程序**、**需求文档**与**文档转换工具**；按 `PROJECT_RULES.md` 组织。

- 设计基准：**3840 × 2160 @30Hz**（独立 75 寸电视），1920×1080 等分辨率下整体等比缩放
- 纯静态前端：**无构建、无第三方库、无 CDN、无外网依赖**（内网隔离环境要求）
- 版本标识：界面右下角显示 `v0.4.0-demo`

---

## 一、怎么跑起来

| 方式 | 操作 |
| --- | --- |
| 最简单 | **双击根目录 `index.html`**，按 `F11` 全屏 |
| 看板全屏 | `msedge --kiosk "file:///<项目路径>/index.html"` |
| 指定页面 | 地址后加 `?tab=0…7`（0 设备状态、1 任务数据、2 班次信息、3 生产统计、4 设备异常、5 维保台账、6 公告备注、7 操作设置） |

> 因为要求"双击即可打开"，本项目**不使用 ES module**（`file://` 下会被浏览器拦截），
> 改用「普通 `<script>` + 全局命名空间」写法，脚本加载顺序见 `index.html`。

### 源码加载顺序

```
config（board.config、fieldMap） → utils（dom、format） → services（api、mockData、mockUpperSource）
  → components（11 个） → pages（Dashboard） → main.js
```

被依赖的先加载；新增文件时同步在 `index.html` 里补一行 `<script>`，并在 `PROJECT_RULES.md` 9.1 登记。

### 数据源切换

| 模式 | 启动方式 | 说明 |
| --- | --- | --- |
| **mock**（默认） | 直接打开 `index.html` | 全部数据由 `services/mockData.js` 生成，用于界面评审 |
| **upper** | 地址栏加 `?source=upper` | 由"上位机报文"经 `services/api.js` 适配层写入，**走与真实接口完全相同的链路**，用于联调前自测 |

真实环境切换只需改 `src/config/board.config.js` 的 `dataSource`，并把 `upper.url`、`mes.baseUrl` 填上。

### 联调模拟工具

| 工具 | 用途 | 启动 |
| --- | --- | --- |
| `tools/mock-upper/` | 模拟设备 PC 上位机，提供符合契约的实时数据 | 双击 `start.cmd`，或 `node tools/mock-upper/mock-upper.js --port 8801` |
| `tools/mock-mes/` | 模拟 MES 端：接收上报、返回回执（可切风格/注异常）、下发派工 | 双击 `start.cmd`，或 `node tools/mock-mes/mock-mes.js --receipt status` |

两者的详细参数见各自目录下的 `README.md`；字段契约以 `src/config/fieldMap.js` 为准。

## 三、演示交互

| 操作 | 效果 |
| --- | --- |
| 点击底部 8 个标签 | 切换页面，头部信息区固定不动（FR-9.1～9.3） |
| 无操作 5 分 10 秒 | 自动回到「设备状态」首页（FR-9.4；**晚于 5 分钟自动锁定**，避免解锁态残留） |
| 设置页输入密码 `8888` | 解锁维保录入、公告发布、时间设置与关键参数配置（FR-8.1、8.6）；解锁后 **5 分钟无写操作自动锁定**（FR-8.2） |
| 解锁后填写并保存 | 内容即时出现在对应页面，并逐条写入「操作日志（留痕）」（FR-8.7 / NFR-15） |
| 键盘 `D` | 模拟上位机断连，演示降级显示（UI-10） |
| 键盘 `A` | 触发一条新故障报警（进入**并发报警队列**，不覆盖旧报警；可在故障卡上「标记处理中 / 确认闭环」，FR-5.6） |
| `?curve=none` | 曲线初始空态（无已完成任务数据） |
| `?link=off` / `?unlock=1` | 以断连 / 已解锁状态启动（评审截图用） |

## 四、数据口径

| 数据项 | 口径 |
| --- | --- |
| **航行器深度 depth** | 相机系统测量的**航行器**水下深度，非相机自身下放深度 |
| **航行速度 speed / vx / vy** | X-Y 平面合成速度与 X、Y 分速度，保持 `speed = √(vx²+vy²)` |
| **实时帧率 / 相机增益 / 快门速度 / 相机水下深度** | 相机侧**设备参数**，实时帧率量程 0～1200 fps（演示取 400 fps），**次要展示**（FR-3.16）；注意 `cameraDepth` 是**相机自身**深度，与航行器深度 `depth` 严格区分 |
| **测试标准阈值** | 相机设定深度/增益/帧率/快门，属设备参数，**次要展示** |
| **19 台相机的取值** | 由 PC 上位机整合后提供单一结果值，看板**不做二次聚合** |
| **MES 上报字段** | 按附录 2 上报 **13 个字段**（含 `depth` 航行器深度与 `cameraDepth` 相机水下深度，两者语义不同）；字段名以 `src/config/fieldMap.js` 为准 |
| **任务曲线** | **按每次测试任务完成更新**，绘制该任务完整曲线（160 采样点），任务进行中显示上一任务曲线 |
| **统计与班次** | 全部由当前时钟与班次进度推导，跨班次（08:00/16:00/00:00）自动清零 |

所有数据均为**模拟数据**，集中在 `src/services/mockData.js` 顶部的 `CFG` 中，可直接调整。
接入真实数据时用 `src/services/api.js` 替换数据来源，界面层无需改动。

## 五、Demo 已实现的需求（覆盖证据见 `tests\README.md` 第三节）

| 需求 | 体现 |
| --- | --- |
| FR-1 头部基础信息 | 设备全称、equipCode、日期星期、秒级时钟、班组/操作员/班组长、班次 |
| FR-2 设备运行状态 | 5 种运行模式 + 色标、航行器深度、**运行阶段（准备 / 运行 / 判定 / 完成）**、联网状态与心跳 |
| FR-3 实时测试任务数据 | 工单 8 项、深度/速度主展示、水平/垂直分速度、进度与结果五态、任务曲线、设备参数次要展示 |
| FR-4 当班生产统计 | 4 组共 15 项统计 |
| FR-5 设备异常与预警 | 故障卡、并发报警队列、闭环状态（含本机录入）、4 类预警、当班异常台账（接收闭环报警，上限 8 条） |
| FR-6 维保台账 | 维保周期、距下次维保进度、当日/本月/年度累计运行、检修记录 |
| FR-7 公告备注 | 车间公告、工艺提示、待办事项 |
| FR-8 系统设置 | 密码解锁（5 分钟自动锁定）、系统时间与 NTP、7 项自检、维保录入与公告发布、关键参数配置、操作日志留痕 |
| FR-9 页面与交互 | 8 标签页、默认首页、头部常显、无操作自动返回、全屏无滚动条 |
| UI-01～UI-19 | 三段式布局、4K 自适应、色彩与字号规范、主次展示层级、任务曲线规范 |

**未包含**（不在演示范围）：历史查询与报表导出（FR-10，P1）、标签页轮播（P2）、真实接口调用（IF-A/B/D，需后端）、报警声音与远程运维（已取消）。

## 六、已知限制

1. 解锁密码校验在**前端**完成，仅为演示；正式实现须由服务端校验并哈希存储（NFR-14）；
2. 维保录入、公告发布与操作日志仅写入浏览器内存，刷新即失效，不落库（DR-18 后落库）；
3. 报警以卡片 + 并发队列 + 降级横幅呈现，未实现弹窗动画（FR-5.5/5.7）；
4. 任务曲线仅保留"上一任务"一条用于展示，正式实现按 DR-18/DR-19 落库；
5. 未接入真实 MES / PC 上位机数据；附录 2 的一致性问题（Q-23）目前悬置；
6. **历史查询与报表（FR-10）不在本期 Demo 范围**（依赖 DR-11/DR-18 落库）；
7. **关键参数配置（FR-8.6）本期只开放设备编号 / 上位机地址 / MES 地址 / 维保到期预警阈值**；
   班次时间与其余判定阈值仍写在 `src/config/board.config.js`（改配置即生效，界面不提供入口）；
8. **FR-7.11（公告/提示的编辑与删除）**：本期只做发布与展示，编辑/删除留待实施阶段；
9. **FR-9.7 的任务栏 / Alt+Tab / Win 键屏蔽**须由 kiosk 启动参数完成（浏览器内只能屏蔽文本选中、
   右键菜单与拖拽），部署参数见 `PROJECT_RULES.md` 与现场部署说明；
10. 稼动率（OEE）目前按配置常量 `production.runRate` 推导，属 Q-11 口径占位（见 `tests/contract-check.js` K 段）；
11. **FR-9.5（标签页轮播）本期未实现**：标签页仅支持手动切换（键盘 `1`～`8` / `Q`·`E` / 点击），
    未做自动轮播；已登记为《后续路线图》技术债 **E3**（2026-09-19 补登记，见审查报告 P3-11）。
