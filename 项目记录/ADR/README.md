# 架构决策记录（ADR）

> **用途：** 记录"为什么这么定"的架构决策，避免几个月后有人（包括我们自己）回头推翻已有取舍。
> **维护规则：** 一个决策一个文件，编号递增；**决策一旦落定不再修改原文**，要改就新写一条并把旧的标 `已取代（由 ADR-XXXX 取代）`；**证据与核查过程放附件**，结论仍写在主 ADR 里、不重复。
> **命名：** 主决策 `ADR-<四位序号>-<短横线连接的英文小写主题>.md`；附件 `ADR-<主决策序号>-附件-<主题>.md`。
> **编码：** UTF-8（无 BOM），换行 CRLF，与 `项目记录\` 其余文档一致；本目录**只放 `.md`**，不做 Word 版本。
> **建档日期：** 2026-09-19
