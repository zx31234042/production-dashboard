## 二、负责人拍定的设计（2026-09-22）

| 决策点 | 结论 |
| --- | --- |
| **FR-8.2 取舍** | **方案乙**：解锁状态在设置页有效，**在任务数据页的标准值录入入口同样有效**（超时仍自动锁定，建议 5 分钟） |
| 单位写法 | 速度统一写 **m/s**（不用 m·s⁻¹）；深度 **m**；均**保留两位小数** |
| 上下限形式 | 按**正负偏差**显示与录入；**基准＝典型值**（上限＝典型值＋上偏差，下限＝典型值＋下偏差） |
| 偏差默认符号 | **下偏差默认负、上偏差默认正**；录入时**不带正负号则按默认口径**处理 |
| MES 上报口径 | `uclValue`/`lclValue` 报**绝对值**（典型值 ± 偏差）；未设定时按 MES 函件 **N-7** 占位（`65535` / `IsPass=null`） |
| 相机参数去向 | 移入任务数据页**二级菜单**，菜单项**只含参数名、设定值、状态**（实测值不展示） |
| 典型值 | **只显示、不参与判定** |
| 超范围着色 | **超范围显示红色**；**保留 FR-3.14 的"临近黄"三态** |
| 复核 | **单人操作、不做二次复核** |
| 历史判定 | **不追溯**（新标准自生效时间起生效） |
| 标准维度 | **产品＋工序** |
| 优先 | FR-3.16 / FR-3.18 / FR-3.19 统一 **P0** |
| 「复制上一标准」 | **不做**。理由：标准按 (产品＋工序) 持久保存，**重复批次无需重录**；仅"首次录入新组合且类似老组合"时才可能有用，而此类场景量程差异大，**复制徒增误用风险**。登记为"已评估、不采纳" |

## 三、录入/修改操作逻辑（八步，负责人给定）

1. 进入**设置页**输入密码解锁；
2. **跳转**到「任务数据」页；
3. 点击**上限 / 下限**的数字；
4. **反色显示**数字（**含高亮框**），并以 **0.5 s 间隔闪烁**；
5. 操作人输入数据（**下偏差默认负数、上偏差默认正数**；**不带正负号按默认口径**）；
6. 按**回车**或**鼠标点击其他区域**退出录入并注入数据；校验「**下限 ≤ 上限**」「**典型值在上下限之间**」，**非法操作弹窗提醒**（不写入）；
7. 录入成功则**记录**（内容、**时间戳**、**班组编号**）；
8. 操作人**主动锁定**，或**长时间未做设置/录入操作** ⇒ **锁定操作功能**，此时**点击数字无响应**。

**配套约束**：**修改前不做任何变更**（未成功注入前，判定与显示都用旧值）；**历史合格判定不追溯**；**典型值只显示**；**单人操作、无二次复核**。
