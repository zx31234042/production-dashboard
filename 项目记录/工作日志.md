## 四、关键决策记录

| 决策 | 结论 | 理由 |
| --- | --- | --- |
| 看板硬件采购方式 | **另项采购**，不进父项目供货清单 | 甲方答复；避免与父项目 BOM 混淆 |
| 显示终端 | **独立 75″ 电视**，与父项目"图像总览大屏"物理分开 | 一物两用会互相抢占，无法同时满足 |
| MES 通讯路径 | **MES 服务器 ↔ 看板主机直连** | 甲方第二轮澄清（撤销了早前"经上位机"的推定） |
| 实时数据来源 | **PC 上位机**（19 台相机整合后的单一结果值） | 看板不做二次聚合，取值规则由上位机负责 |
| `depth` 语义 | **航行器水下深度**（相机系统测量），非相机下放深度 | 甲方澄清；据此改写了对比表与接口字段 |
| 前端技术选型 | 纯静态、**不用 ES module**、不引第三方库 | 需支持双击 `index.html` 打开；内网隔离、无外网依赖（NFR-25） |
| 组件写法 | IIFE + 全局命名空间 | 与"不用 ES module"约束配套 |
| 文档目录 | 保留中文目录，不并入 `docs\` | `来源文件`（只读）/`需求文档`（可改）/`输出文件`（交付）流转规则不同，物理隔离更安全 |
| 甲方原件是否入版本库 | **不入**，写入 `.gitignore` | 父项目设计方案第 19 章有保密要求 |

## 五、遇到的问题与解决

| 问题 | 原因 | 解决 |
| --- | --- | --- |

| 看板页面多处留白、卡片裁切 | 大屏布局中列表/表格不撑满、行高不足 | 逐屏截图核对，压缩行高、拆分主/次标题、调整网格行高 |

| 任务曲线挤在一角、溢出 | 曲线宽度按固定点数组绘制，未按卡宽自适应 | 改为按容器宽度等比绘制，并加空态提示 |
