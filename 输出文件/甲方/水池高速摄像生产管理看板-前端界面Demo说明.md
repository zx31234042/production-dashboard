## 一、总体说明

- 界面按 **3840×2160@30Hz** 设计，在 1920×1080 等分辨率下整体等比缩放，不出现滚动条（UI-02）；
- 整体分三个区域：**顶部固定信息区**（FR-1，切换页面时不消失）、**中部信息展示区**（8 个标签页）、**底部标签栏**（FR-9，含链路状态）；
- 演示密码 8888；快捷键 D 模拟上位机断连、A 触发一次新报警；
- 解锁后 **5 分钟无写操作自动回到锁定状态**（FR-8.2）；解锁后的每次录入 / 发布 / 参数修改都会写入**操作日志**（FR-8.7、NFR-15）；
- 大屏交互屏蔽：禁用文本选中、右键菜单与拖拽（FR-9.7；任务栏 / Alt+Tab / Win 键须由 kiosk 启动参数屏蔽）；
- 评审辅助参数：`?tab=0…7` 直接打开指定页面，`?curve=none` 查看曲线初始空态，`?link=off` 查看断连降级态，`?unlock=1` 直接进入已解锁状态。

| --- | --- | --- |
| 1 | 设备状态 | 设备运行模式、航行器深度与速度实测主参数、任务曲线 |
| 2 | 任务数据 | 当前工单信息、实时实测数据、测试进度与结果、设备参数 |
| 3 | 班次信息 | 班次时段、当班人员、当班时间进度 |
| 4 | 生产统计 | 当班任务、完成情况、质量质检、设备效率四组统计 |
| 5 | 设备异常 | 实时故障报警、并发报警队列、预防性预警、当班异常台账 |
| 6 | 维保台账 | 维保周期、设备累计运行、近期检修记录 |
| 7 | 公告备注 | 车间公告、测试工艺提示、待办事项提醒 |
| 8 | 操作设置 | 密码解锁、系统时间设置、系统自检、维保录入与公告发布、关键参数配置、操作日志 |

## 二、设备状态

设备运行模式与实测主参数总览，是看板的默认首页。

![图 1　设备状态页](..\..\src\assets\screenshots\01-设备状态-任务曲线.png)

| 功能区 | 说明 |
| --- | --- |
| 设备运行模式 | 大字显示当前模式（待机 / 测试运行 / 正常停机 / 维保检修 / 故障锁定），左侧色带与文字同步配色；下方列出 5 种模式与状态色标，当前项高亮 |
| 联网状态 | 与 PC 上位机的连接状态（在线正常 / 离线断连），并显示心跳与数据延迟 |
| 实测主参数 | **航行器深度、航行速度**为主展示对象（大号数值），另列水平速度 vx、垂直速度 vy 与实时运行时长 |
| 设备参数（次要） | 相机侧参数：实际帧率、相机增益、快门速度，以虚线次要条呈现，供维保与排查使用 |
| 任务曲线 | 航行器深度曲线、航行速度曲线：**按每次测试任务完成更新一次**，绘制该任务的完整曲线，图下标注件号、采样点数、任务时长与量程 |

## 十一、演示交互一览

| 操作 | 效果 |
| --- | --- |
| 点击底部标签 | 切换页面，头部信息区固定不动 |
| 无操作 5 分 10 秒 | 自动回到「设备状态」首页（晚于 5 分钟自动锁定，避免解锁态残留） |
| 设置页输入 `8888` 并解锁 | 开放维保录入、公告发布与系统时间设置 |
| 解锁后保存维保记录 / 发布公告 / 修改参数 | 内容即时出现在对应页面（参数类刷新页面后生效），并逐条写入「操作日志（留痕）」 |
| 解锁后 5 分钟无写操作 | 自动回到锁定状态，并写入一条「自动锁定」操作日志 |
| 键盘 `D` | 模拟上位机断连，演示降级显示 |
| 键盘 `A` | 触发一条新的故障报警（入队不覆盖旧报警），演示并发排队与闭环流转 |
