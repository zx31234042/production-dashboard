## 一、总体说明

- 界面按 **3840×2160@30Hz** 设计，在 1920×1080 等分辨率下整体等比缩放，不出现滚动条（UI-02）；
- 整体分三个区域：**顶部固定信息区**（FR-1，切换页面时不消失）、**中部信息展示区**（8 个标签页）、**底部标签栏**（FR-9，含链路状态）；
- 演示密码 8888；快捷键 D 模拟上位机断连、A 触发一次新报警；
- 解锁后 **5 分钟无写操作自动回到锁定状态**（FR-8.2）；解锁后的每次录入 / 发布 / 参数修改都会写入**操作日志**（FR-8.7、NFR-15）；
- 大屏交互屏蔽：禁用文本选中、右键菜单与拖拽（FR-9.7；任务栏 / Alt+Tab / Win 键须由 kiosk 启动参数屏蔽）；
- 评审辅助参数：`?tab=0…7` 直接打开指定页面，`?curve=none` 查看曲线初始空态，`?link=off` 查看断连降级态，`?unlock=1` 直接进入已解锁状态。

## 二、设备状态

设备运行模式与实测主参数总览，是看板的默认首页。

![图 1　设备状态页](..\..\src\assets\screenshots\01-设备状态-任务曲线.png)

| 功能区 | 说明 |
| --- | --- |
| 设备运行模式 | 大字显示当前模式（待机 / 测试运行 / 正常停机 / 维保检修 / 故障锁定），左侧色带与文字同步配色；下方列出 5 种模式与状态色标，当前项高亮 |
| 联网状态 | 与 PC 上位机的连接状态（在线正常 / 离线断连），并显示心跳与数据延迟 |
| 实测主参数 | **航行器深度、航行速度**为主展示对象（大号数值），另列水平速度 vx、垂直速度 vy 与实时运行时长 |
| 设备参数（次要） | 相机侧参数：实际帧率、相机增益、快门速度，以虚线次要条呈现，供维保与排查使用 |
| 任务曲线 | 航行器深度曲线、航行速度曲线：**按每次测试任务完成更新一次**，绘制该任务的完整曲线，图下标注件号、采样点数、任务时长与量程 |

## 三、任务数据

当前工单、实时实测数据、测试进度与结果，以及设备参数与设定阈值。

![图 2　任务数据页](..\..\src\assets\screenshots\02-任务数据.png)

| 功能区 | 说明 |
| --- | --- |
| 当前工单信息 | 工单编号、产品型号与名称、产品批次、生产订单编号、图号、计划测试数量、工序 |
| 实时实测数据 | 航行器深度与航行速度为主展示（大号数值），水平 / 垂直分速度次之 |

| 设备参数与设定阈值 | 次要区：相机设定深度、设定帧率、相机增益、快门速度，显示设定值、实际值、偏差与判定（正常 / 临近 / 超标） |

当班周期内的生产、质检与效率数据，替代人工纸质台账。

![图 4　生产统计页](..\..\src\assets\screenshots\04-生产统计.png)

| 功能区 | 说明 |
| --- | --- |

## 六、设备异常

实时故障报警、预防性预警与当班异常台账，实现风险实时管控与异常闭环追溯。

![图 5　设备异常页](..\..\src\assets\screenshots\05-设备异常.png)

| 功能区 | 说明 |
| --- | --- |
| 实时故障报警 | 故障代码（大字）、故障类型、故障简述、发生时间、等级、处理人与处理措施（取自故障字典的处理建议）；下方显示异常闭环状态（未处理 / 处理中 / 已闭环 / 复检确认中），有故障时整卡转为红色主题；并提供「标记处理中 / 确认闭环」本机闭环录入按钮 |
| 并发报警队列 | 多条报警同时发生时**按发生时间排队、互不覆盖**：卡片展示队首报警，队列内其余报警逐条列出等级、代码、类型、简述、入队时间与闭环状态（FR-5.6） |
| 预防性预警 | 参数阈值临近、设备维保到期、耗材更换、工单超时四类预警，按等级以黄 / 红 / 绿标识 |
| 当班异常台账 | 最新 5 条历史异常及闭环记录：发生时间、故障代码、故障简述、闭环状态 |

## 九、操作设置

看板输入解锁、系统时间设置、系统自检，以及解锁后的维保录入与公告发布。

![图 8　操作设置页](..\..\src\assets\screenshots\08-操作设置.png)

| 功能区 | 说明 |
| --- | --- |
| 看板输入解锁 | 密码输入框与解锁 / 锁定按钮；未解锁时下方录入与发布功能不可用 |
| 系统时间设置 | 当前系统时间、时间来源、NTP 服务器与同步状态；以 NTP 同步优先，手工设置需解锁 |
| 系统状态自检 | 看板主机网络、PC 上位机连接、MES 接口连通性、MES 上报队列、本地数据库、磁盘空间、NTP 时间同步 |
| 操作日志（留痕） | 解锁后的维保录入、公告发布、参数配置、时间同步等写操作逐条留痕（时间、动作、明细、操作人），演示保留最近 20 条（FR-8.7 / NFR-15）；报警的处置与闭环同样入日志 |
| 关键参数配置 | 解锁后可直接修改设备编号、PC 上位机地址、MES 接口地址与维保到期预警阈值，保存后写入本地配置并记录操作日志（FR-8.6） |
| 维保信息录入 / 公告信息发布 | 解锁后可录入检修内容、责任人与验收状态并保存；可发布车间公告（含公告类型与内容） |

## 十、特殊状态

### 10.1 曲线初始空态

设备状态页在**无已完成任务数据**时，曲线区显示坐标网格框架与提示文案；完成一次测试任务后自动绘制完整曲线。

![图 9　曲线初始空态](..\..\src\assets\screenshots\09-曲线初始空态.png)

### 10.2 上位机断连降级

与 PC 上位机断连时，运行模式转为「故障锁定」、联网状态转红、受影响数据区显示「数据已冻结 · 最后更新时间」，并在底部弹出降级提示横幅。

![图 10　上位机断连降级](..\..\src\assets\screenshots\10-上位机断连降级.png)

## 十一、演示交互一览

| 操作 | 效果 |
| --- | --- |
| 点击底部标签 | 切换页面，头部信息区固定不动 |
| 无操作 5 分 10 秒 | 自动回到「设备状态」首页（晚于 5 分钟自动锁定，避免解锁态残留） |
| 设置页输入 `8888` 并解锁 | 开放维保录入、公告发布与系统时间设置 |
| 解锁后保存维保记录 / 发布公告 / 修改参数 | 内容即时出现在对应页面（参数类刷新页面后生效），并逐条写入「操作日志（留痕）」 |
| 解锁后 5 分钟无写操作 | 自动回到锁定状态，并写入一条「自动锁定」操作日志 |
| 键盘 `D` | 模拟上位机断连，演示降级显示 |
| 键盘 `A` | 触发一条新的故障报警（入队不覆盖旧报警），演示并发排队与闭环流转 |
