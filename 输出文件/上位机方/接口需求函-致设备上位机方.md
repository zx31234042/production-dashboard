## 一、背景说明

按甲方澄清，**看板主机不直连相机、补光灯、深度传感器与同步控制器**。所有实时数据由 PC 上位机采集并整合后，经局域网提供给看板主机。

因此本项目的**唯一实时数据来源**是贵方上位机。目前该接口的规范尚未提供，需贵方明确后我方方可实现取数与显示。

```
相机 / 补光灯 / 深度传感器 / 同步控制器
        ↓（贵方采集与整合）
   PC 上位机  ──→  看板主机（本项目）  ──→  MES 服务器
                    （MES 通讯由看板主机直连，不经上位机）
```

本函共四部分：**接口规范（第二章）、数据项（第三章）、口径与参数确认（第四章，含附录 2 与网络接入）、时间要求**。

## 三、需贵方提供的数据项（看板显示所必需）

请按下表确认**能否提供**、**实际字段名**与**单位**；若某项无法提供，请注明原因，我方将调整为不显示或改为人工录入。

### 3.1 设备运行状态类（建议 1 s 刷新）

| 序号 | 数据项 | 用途 | 备注 |
| --- | --- | --- | --- |
| 1 | **运行模式**（待机 / 测试运行 / 正常停机 / 维保检修 / 故障锁定） | 设备状态页主标识，按颜色区分 | 请提供贵方的状态码字典及与这 5 种模式的**映射关系** |
| 2 | **运行阶段**（**准备 / 运行 / 判定 / 完成**） | 设备状态页显示当前阶段 | 已按甲方要求由 6 阶段简化为 4 阶段 |
| 3 | 设备联网/通讯状态 | 判断数据是否有效（在线正常 / 离线断连 / 数据传输异常） | 可由链路本身判断，如贵方有状态字请一并提供 |
| 4 | 设备累计运行时长（当日/本月/年度） | 维保台账与累计运行统计 | 若贵方不提供，我方按接收状态自行累计 |

### 3.2 实时实测数据类（测试中建议 100～500 ms）

| 序号 | 数据项 | 字段标识 | 单位 | 说明 |
| --- | --- | --- | --- | --- |
| 5 | **航行器水下深度** | `depth` | m | **航行器**的水下深度（相机系统的测量结果） |
| 6 | **航行速度** | `speed` | m/s | 航行器 X-Y 平面合成速度 |
| 7 | **水平速度** | `velocity_x` | m/s | 航行器 X 方向分速度 |
| 8 | **垂直速度** | `velocity_y` | m/s | 航行器 Y 方向分速度 |

> 深度与速度为看板的**主要展示对象**，要求数值稳定、无跳变（数据跳变会触发异常告警）。

## 附录：甲方《信息化看板显示内容》附录 2 全文（由贵方编制）

> **来源说明：** 本附录取自甲方来源文件《信息化看板显示内容》，该附录由**贵方（设备 PC 上位机方）编制**。现将当前版本全文列于此，请核对确认（对应 C-6）。

### 1. 接口基础要求

- 接口地址、端口、请求头由 MES 方提供，联调阶段完成确认；
- 传输方式：内网 HTTP POST；备用传输方案 WebService；
- 数据格式：标准 JSON；
- 唯一校验字段：设备编号（必填）；
- 数据推送方式：周期定时上传，测试运行过程持续推送实时瞬时工艺数据。

### 2. 上传报文字段说明（共 13 项）

| 参数名称 | 字段标识 | 数据来源 | 数据类型 | 说明 |
| --- | --- | --- | --- | --- |
| 设备编号 | `equipCode` | MES 工单 | 字符串 | 唯一匹配标识，必填 |
| 生产任务编号 | `procOrderNo` | MES 工单 | 字符串 | 本次水下测试工单编号 |
| 实时帧率 | `frameRate` | PC上位机 | 整型 | 高速相机当前实际帧率 |
| 相机增益 | `gain` | PC上位机 | 浮点型 | 相机实时增益参数 |
| 快门速度 | `shutter` | PC上位机 | 整型 | 相机当前快门参数 |
| 相机水下深度 | `cameraDepth` | PC上位机 | 浮点型 | 现场传感器采集深度数值 |
| 实测水下深度 | `depth` | PC上位机 | 浮点型 | 航行器水下深度 |
| 实测航行速度 | `speed` | PC上位机 | 浮点型 | 航行器 X-Y 平面合成速度 |
| 实测水平速度 | `velocity_x` | PC上位机 | 浮点型 | 航行器 X 方向分速度 |
| 实测垂直速度 | `velocity_y` | PC上位机 | 浮点型 | 航行器 Y 方向分速度 |
| 采集时间 | `collectTime` | Java 程序 | 字符串 | 时间格式 `yyyy-MM-dd HH:mm:ss` |
| 设备运行状态 | `testStatus` | PC上位机 | 整型 | 0=待机 1=测试中 2=测试完成 3=设备异常 |
| 上传流水号 | `uploadId` | Java 程序生成 | 字符串 | 用于 MES 数据去重、回执核对 |

### 3. 报文示例

**请求报文：**

```json
{
  "equipCode": "SX-UNDERWATER-001",
  "procOrderNo": "MES20260728001",
  "frameRate": 400,
  "gain": 2.5,
  "shutter": 500,
  "cameraDepth": 12.00,
  "depth": 12.68,
  "speed": 5.0,
  "velocity_x": 4.9,
  "velocity_y": 0.1,
  "collectTime": "2026-07-28 15:30:22",
  "testStatus": 1,
  "uploadId": "UP20260728153022001"
}
```

**成功返回回执：**

```json
{ "code": 200, "msg": "数据接收成功", "uploadId": "UP20260728153022001" }
```

**异常返回回执：**

```json
{ "code": 5001, "msg": "设备编号不存在/关键字段缺失", "uploadId": "UP20260728153022001" }
```
